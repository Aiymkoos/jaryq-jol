# Jaryq Jol — веб-версия

Ассистент для незрячих и слабовидящих: распознаёт обстановку, читает текст
и называет текущий адрес — **прямо в браузере**, без установки.

Открывается по ссылке на телефоне и на ноутбуке. Ничего скачивать не нужно.

---

## Почему браузер, а не мобильное приложение

Это не упрощение, а способ снять блокировку, которая держалась месяцами.

В мобильной версии ([Qamqor Vision](https://github.com/Aiymkoos/qamqor-vision))
чтение текста реализовать не удалось:

1. On-device движок распознавания текста ML Kit поддерживает латиницу,
   китайский, деванагари, японский и корейский — **кириллицы в списке нет**.
   Ни казахский, ни русский текст им не прочитать.
2. Единственный офлайн-движок для кириллицы — Tesseract. Но его обвязка
   для Flutter вызывает в своём `build.gradle` закрытый в 2021 году
   `jcenter()` и прибита к Android Gradle Plugin 7.1.2 — сборка падает
   на этапе конфигурации.

В браузере обеих проблем не существует: Tesseract подключается как обычная
библиотека и читает кириллицу без сервера, без ключей и без оплаты.

Заодно снялось второе ограничение. В мобильной версии детекция объектов
работала с выключенной классификацией — базовая модель различала предметы
слишком грубо, и связать рамку с названием значило рискнуть фразой
«стол слева», когда слева стул. Здесь COCO-SSD отдаёт рамку и класс
за один проход, поэтому предметы можно называть по имени.

## Что работает

* **Распознавание обстановки.** COCO-SSD через TensorFlow.js, 80 классов
  предметов, прямо на устройстве. Из рамки считается «слева / по центру /
  справа» и «близко / далеко»: «Стул по центру, близко.»
* **Приоритет опасного.** Машина, человек, собака, светофор объявляются
  первыми, даже если занимают меньше кадра, чем стена за ними.
* **Чтение текста.** Tesseract.js с русским и казахским словарями сразу —
  на упаковке лекарства и на вывеске языки соседствуют, а спрашивать
  незрячего человека, на каком языке текст, которого он не видит,
  бессмысленно.
* **Определение адреса.** Геопозиция браузера плюс Nominatim
  (OpenStreetMap): «Вы находитесь: улица Сатпаева, Коктем.»
* **Голосовой вывод** с прерыванием предыдущей фразы, повтором
  и остановкой. Три ступени скорости, называются вслух уже на новой скорости.
* **Управление вслепую.** Панель занимает большую часть экрана и сама
  работает кнопкой: двойное касание описывает обстановку, попадать пальцем
  в кнопку не нужно. Для TalkBack и VoiceOver объявлена роль кнопки —
  скринридеры перехватывают жесты, и без этого функция не досталась бы тем,
  для кого сделана.
* **Двуязычность.** Казахский и русский для интерфейса и голоса. Если
  казахского голоса нет в системе, приложение **говорит об этом вслух**
  и переходит на запасной, вместо того чтобы молча замолчать.
* **Настройки переживают перезагрузку** страницы.
* **Доступный интерфейс.** Контраст около 11:1 при минимуме 4.5:1 для
  WCAG AA, зоны нажатия 88px при минимуме 44px, видимая рамка фокуса.

### Принцип: не выдумывать

Незрячий пользователь не может перепроверить ответ глазами, поэтому
приложение никогда не заполняет пробелы догадками.

Это не лозунг, а работающий код:

* Слова с уверенностью ниже 60 отбрасываются; если выжило меньше половины
  слов, ответ считается пустым. Tesseract на смазанном кадре уверенно
  возвращает правдоподобный мусор вида `Ilapauero.viom 5OO wr`, и зачитать
  такое с упаковки лекарства **опаснее, чем промолчать**.
* Предмет называется по имени только при уверенности выше 0.62. Ниже —
  звучит «Препятствие по центру», без догадки о том, что это за предмет.
* При низкой точности геопозиции адрес называется с прямой оговоркой,
  что он может быть неверным.

Проверено: на белом кадре и на случайном шуме распознавание текста
возвращает пусто, а не выдуманные слова.

## Чего пока нет

* **Построения маршрута.** Публичный демо-сервер OSRM отвечает на запрос
  пешеходного профиля, но считает по автомобильной сети — в ответе приходит
  `"mode":"driving"`. Вести незрячего человека по дороге для машин
  и называть это пешеходным маршрутом нельзя. Нужен собственный OSRM
  с профилем `foot` либо ключ OpenRouteService.
* **Ступеней и открытых дверей.** В наборе классов COCO их нет. Требуется
  свой размеченный датасет и дообучение — на глаз это не решается.
* **Непрерывного режима.** Сейчас кадр снимается по нажатию. Режим
  «на ходу» требует подавления повторов и гистерезиса, иначе приложение
  станет невыносимо болтливым.
* **Казахского голоса.** Его нет почти ни в одной системе — это
  ограничение платформы, а не приложения. Приложение честно сообщает
  о переходе на русский голос.

## Технологии

| Что | Чем | Где выполняется |
|---|---|---|
| Распознавание предметов | TensorFlow.js + COCO-SSD | на устройстве |
| Чтение текста | Tesseract.js (`rus` + `kaz`) | на устройстве |
| Синтез речи | Web Speech API | на устройстве |
| Адрес по координатам | Nominatim (OpenStreetMap) | сеть |

Камера, кадр и распознанный текст **не покидают вкладку**. В сеть уходит
единственный запрос — координаты в Nominatim при нажатии «Где я».

Сборки нет: это статические файлы, которые браузер исполняет как есть.

## Структура

```
docs/
├── index.html
├── css/style.css
└── js/
    ├── i18n.js         # строки интерфейса на kk и ru
    ├── labels.js       # 80 классов COCO → kk / ru + опасные классы
    ├── speech.js       # синтез речи, запасной голос
    ├── camera.js       # доступ к камере и снятие кадра
    ├── ocr.js          # Tesseract.js и отсев недостоверного текста
    ├── vision.js       # COCO-SSD, положение, сборка фразы
    ├── navigation.js   # геопозиция и адрес
    └── app.js          # экран и обработчики
```

## Запуск локально

Камера и геопозиция работают только на `https` или на `localhost`.

```bash
cd docs
python -m http.server 8777
```

Затем открыть `http://localhost:8777`.

При первом запуске распознавание текста скачивает словари (около 30 секунд),
модель предметов — веса (около 20 секунд). Дальше обе работают из кэша:
повторное чтение текста занимает примерно 1.3 секунды.

## Происхождение

Основано на [Qamqor Vision](https://github.com/Aiymkoos/qamqor-vision) —
открытом проекте того же автора под лицензией MIT. Оттуда перенесены
продуктовые решения, проверенные в мобильной версии: контрастная тема,
управление двойным касанием по всей панели, трёхступенчатая скорость речи,
поведение при отсутствующем казахском голосе, словарь названий предметов
и принцип «не выдумывать».

Заново написаны: распознавание предметов с названиями, чтение кириллицы,
определение адреса и весь код веб-версии.

*Идея проекта родилась из личного опыта: сестра автора потеряла зрение
на один глаз после осложнений при родах, вызванных диабетом.*
