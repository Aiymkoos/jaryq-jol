# Jaryq Jol — простой экран

Камера, описание предметов, чтение текста на русском и казахском, определение адреса и озвучка. Исправлены отмена ожидающих ответов, очистка камеры, повреждённые настройки и повторная загрузка моделей после ошибки. Расстояние до предмета по размеру рамки больше не объявляется.

Это вспомогательный прототип, не средство подтверждения безопасности пути. Маршрутов на этом простом экране нет. Основная версия с пешеходными маршрутами находится в `webapp/`; workflow Pages публикует её.

OCR отклоняет неуверенный результат целиком, не вырезает слова. Ошибки распознавания всё ещё возможны. Не использовать для определения дозировки лекарства.

При первом использовании требуется интернет для библиотек и моделей. Определение адреса отправляет координаты в Nominatim. Кадры обрабатываются в браузере. Полный офлайн и работа в фоне не заявляются. Реальные проверки на iPhone/Android ещё необходимы.

Локально: из корня проекта `python3 -m http.server 8777`, открыть `/docs/` или `/webapp/`.
