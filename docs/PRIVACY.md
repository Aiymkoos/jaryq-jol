# Данные и границы прототипа

Фотографии обрабатываются локально: ML Kit/Tesseract на Android, TensorFlow.js/Tesseract.js в браузере. Веб-страница загружает библиотеки и модели с CDN: CDN видит сетевой запрос загрузки, но не получает кадр через приложение. Временные изображения не сохраняются в галерею.

После согласия адрес передаётся Nominatim, координаты маршрута — FOSSGIS. Публичные сервисы могут вести журналы. Тайлы карты приходят с OpenStreetMap. Разрешение геолокации запрашивается отдельно браузером/ОС. История прогулок не отправляется собственному серверу и не сохраняется в аккаунте.

Голосовой ввод использует сервис устройства/браузера, который может обрабатывать аудио онлайн. Приложение само не записывает аудиофайлы. Озвучка зависит от установленных системных голосов.

Язык, скорость и размер текста сохраняются только локально. Приложение не требует регистрации, доступа к контактам или медицинским данным.

Это ассистивный прототип, не медицинская диагностика и не средство гарантированного предотвращения столкновений. Он не определяет безопасный момент для перехода дороги и не подтверждает правильность дозировок/лекарств по OCR. Свет, погода, точность GPS, доступность тротуаров и ошибки карты влияют на результат.
