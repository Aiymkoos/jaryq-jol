# Jaryq Jol

Помощник для прогулок по Алматы: пешеходные маршруты, голосовые подсказки, описание предметов и чтение текста на русском и казахском. MedTech-прототип.

Веб-версия: https://aiymkoos.github.io/jaryq-jol/

## Запуск веб-версии

Из корня: `python3 -m http.server 8777`, затем открыть `http://localhost:8777/webapp/`.
Для камеры и GPS на телефоне нужна опубликованная HTTPS-ссылка. Основная версия находится в `webapp/`. Исправленный простой экран Claude сохранён в `docs/`.

Проверки: `npm test --prefix webapp`. Сборка: `npm run build --prefix webapp`; результат в `webapp/dist/`.
Workflow `.github/workflows/pages.yml` публикует основную версию из main через GitHub Actions.

## Возможности и ограничения

- Пешеходный профиль FOSSGIS/OSRM; ручной поиск мест в Алматы через Nominatim. Перед отправкой координат запрашивается согласие.
- Подсказки расстояния до поворота; неточные и устаревшие GPS-данные приостанавливают подсказки. GPS не определяет безопасность перехода и доступность тротуара.
- «Где я» называет примерный адрес и точность GPS; без интернета — координаты.
- COCO-SSD обрабатывает кадр на устройстве; нет измерения расстояний, распознавания ям или гарантированного обнаружения препятствий в темноте.
- Tesseract читает русский и казахский. Если хотя бы одно слово распознано неуверенно, весь результат отклоняется: пропущенное «не» или неверная цифра опаснее молчания. Бледный или мелкий текст распознаватель может не заметить совсем и пропустить без предупреждения. Не использовать для принятия решений о лекарствах.
- Интернет нужен для маршрутов, карт, адресов и первой загрузки моделей. Полный офлайн не заявляется. При уходе в фон сопровождение приостанавливается.

## Голосовые команды

Свободный диалог с языковой моделью не подключён: помощник понимает только эти действия. Доступность голосов и голосового ввода зависит от браузера и устройства.

| Действие | По-русски | Қазақша |
|---|---|---|
| Остановить всё | «стоп», «остановись», «замолчи» | «тоқта» |
| Повторить последний ответ | «повтори» | «қайтала» |
| Прочитать текст | «прочитай текст» | «мәтінді оқып бер» |
| Описать, что перед камерой | «что передо мной», «что вокруг», «опиши» | «айналада не бар», «сипатта» |
| Назвать, где я | «где я» | «қайдамын» |
| Найти место и построить маршрут | «найди парк Горького», «маршрут до вокзала», «проведи до …» | «Көк төбеге барғым келеді» |

На любую другую фразу помощник перечисляет эти команды вслух.

## Android

Исходники Flutter находятся в `qamqor_vision/`. CI собирает отладочный APK (`jaryq-jol-android-demo` в артефактах запуска «Validate and package»), но на реальном устройстве он ещё не проверялся. Для демонстрации на iPhone используется веб-версия; нативной iOS-сборки нет.

Android-версия отстаёт от веб-версии:

- исправленная логика подсказок до поворота (не пропускать поворот заранее, называть расстояние) не перенесена в Dart;
- язык распознавания текста не переключается: всегда `rus+kaz`, независимо от языка интерфейса;
- казахская форма «…ға барғым келеді» не распознаётся как команда маршрута;
- основной экран `CompanionScreen` не покрыт автоматическими тестами: виджет-тесты проверяют прежний `HomeScreen`, который в приложении не открывается.

## Проверки

- Веб: 21 автоматический тест (`npm test --prefix webapp`), статическая сборка выполнена.
- Flutter: `flutter analyze` без замечаний, 39 тестов (`flutter test`), сборка web и APK в CI.

Тесты с подставными ответами проверяют отмену, ошибки камеры, OCR, адреса и GPS-логику. Они не заменяют тестирование камеры, голоса и маршрута на реальном телефоне.
