# Jaryq Jol

Помощник для прогулок по Алматы: пешеходные маршруты, голосовые подсказки, описание предметов и чтение текста на русском и казахском. MedTech-прототип.

## Запуск веб-версии

Из корня: `python3 -m http.server 8777`, затем открыть `http://localhost:8777/webapp/`.
Для камеры и GPS на телефоне нужна опубликованная HTTPS-ссылка. Основная версия находится в `webapp/`. Исправленный простой экран Claude сохранён в `docs/`.

Проверки: `npm test --prefix webapp`. Сборка: `npm run build --prefix webapp`; результат в `webapp/dist/`.
Workflow `.github/workflows/pages.yml` публикует основную версию из main при настройке GitHub Pages Source = GitHub Actions. До успешного запуска workflow публикация не подтверждена.

## Возможности и ограничения

- Пешеходный профиль FOSSGIS/OSRM; ручной поиск мест в Алматы через Nominatim. Перед отправкой координат запрашивается согласие.
- Подсказки расстояния до поворота; неточные и устаревшие GPS-данные приостанавливают подсказки. GPS не определяет безопасность перехода и доступность тротуара.
- COCO-SSD обрабатывает кадр на устройстве; нет измерения расстояний, распознавания ям или гарантированного обнаружения препятствий в темноте.
- Tesseract читает русский и казахский. Результат может содержать ошибки; не использовать для принятия решений о лекарствах.
- Голосовые команды ограничены перечисленными действиями. Свободный диалог с языковой моделью не подключён. Доступность голосов и голосового ввода зависит от браузера и устройства.
- Интернет нужен для маршрутов, карт, адресов и первой загрузки моделей. Полный офлайн не заявляется. При уходе в фон сопровождение приостанавливается.

## Android

Исходники Flutter находятся в `qamqor_vision/`. Имя внутренней папки сохранено для совместимости. CI подготовлен, но мобильная сборка и проверки на реальном устройстве ещё не подтверждены. Для демонстрации на iPhone используется веб-версия; нативной iOS-сборки нет.

## Проверка этого архива

19 автоматических тестов прошли; статическая веб-сборка выполнена. Тесты с подставными ответами проверяют отмену, ошибки камеры, OCR, адреса и GPS-логику. Они не заменяют тестирование камеры, голоса и маршрута на реальном телефоне.
